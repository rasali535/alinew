# Mari AI — Closed-Loop Intelligence Architecture

## 1. Closed-Loop Progression
```
DATA → INSIGHT → REASON → RECOMMENDATION → ACTION → MEASURE → FEEDBACK → PROGRESSION
```

## 2. Activity Stream Events
Mari maintains an immutable audit and interaction stream:
- `OPPORTUNITY_IDENTIFIED`: Strategic gaps discovered in pipeline or audience reach.
- `GROWTH_CAMPAIGN_CREATED`: Campaigns drafted in Growth Studio via Mari orchestration.
- `SOCIAL_POST_SCHEDULED`: Video reels and carousel posts scheduled on Meta Graph APIs.
- `CRM_FOLLOWUP_DISPATCHED`: Commercial proposals re-engaged.
- `OUTCOME_MEASURED`: Real-world conversions (+38.4% reach, 31 leads, $45,000 deal advance).

## 3. Human-in-the-Loop Governance
- All external publishing and financial actions require explicit user confirmation.
- Destructive operations are strictly prevented from autonomous execution.
- Sensitive credentials, OAuth tokens, and secrets are sanitized prior to prompt generation.
