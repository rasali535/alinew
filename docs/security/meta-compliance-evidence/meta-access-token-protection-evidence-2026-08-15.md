## 1. Application-Level Token Encryption

Ralion enforces application-level cryptographic protection for all Meta API user access tokens and refresh tokens prior to database persistence.

### 1.1 Cryptographic Algorithm & Parameters
* **Algorithm:** `AES-256-GCM` (Advanced Encryption Standard in Galois/Counter Mode with Authenticated Encryption).
* **Key Derivation:** 256-bit cryptographic key derived via `SHA-256` hashing of the protected server environment secret `OAUTH_ENCRYPTION_KEY`.
* **Initialization Vector (IV):** Cryptographically random 96-bit (12-byte) initialization vector generated per encryption operation via `crypto.randomBytes(12)`.
* **Authentication Tag:** 128-bit (16-byte) authentication tag generated by the GCM cipher (`cipher.getAuthTag()`) to verify ciphertext authenticity and prevent ciphertext tampering.
* **Storage Envelope Format:** `enc_gcm_v2_{iv_hex}_{tag_hex}_{ciphertext_hex}`.

### 1.2 Implementation Excerpt: Token Encryption Core (`packages/integrations/src/core/crypto.ts`)

```typescript
// Location: packages/integrations/src/core/crypto.ts
import * as crypto from 'crypto';

export function encryptToken(token: string): string {
  if (!token) return '';
  const key = getEncryptionKey(); // 256-bit SHA-256 derived key
  const iv = crypto.randomBytes(12); // 96-bit random IV per operation
  const cipher = crypto.createCipheriv('aes-256-gcm', key, iv);

  const encrypted = Buffer.concat([
    cipher.update(token, 'utf8'),
    cipher.final()
  ]);
  const authTag = cipher.getAuthTag(); // 128-bit authentication tag

  // Returns authenticated version 2 ciphertext envelope
  return `enc_gcm_v2_${iv.toString('hex')}_${authTag.toString('hex')}_${encrypted.toString('hex')}`;
}

export function decryptToken(encryptedEnvelope: string): string {
  if (!encryptedEnvelope) return '';
  if (encryptedEnvelope.startsWith('enc_gcm_v2_')) {
    const parts = encryptedEnvelope.replace('enc_gcm_v2_', '').split('_');
    const [ivHex, tagHex, dataHex] = parts;

    const key = getEncryptionKey();
    const decipher = crypto.createDecipheriv('aes-256-gcm', key, Buffer.from(ivHex, 'hex'));
    decipher.setAuthTag(Buffer.from(tagHex, 'hex')); // Authenticates integrity tag

    return Buffer.concat([
      decipher.update(Buffer.from(dataHex, 'hex')),
      decipher.final()
    ]).toString('utf8');
  }
  // Fallback for legacy format with backward compatibility
  return decryptLegacy(encryptedEnvelope);
}
```

### 1.3 Server-Side Token Management Excerpt (`apps/ralion/src/lib/services/metaCredential.service.ts`)

```typescript
// Location: apps/ralion/src/lib/services/metaCredential.service.ts
export class MetaCredentialService {
  /**
   * Encrypt and store Meta OAuth credentials before database persistence
   */
  static async saveToken(params: SaveMetaTokenParams): Promise<boolean> {
    const supabase = getServiceSupabase();
    // Tokens are immediately encrypted using AES-256-GCM before writing to the database
    const encryptedAccessToken = encryptToken(params.accessToken);
    const encryptedRefreshToken = params.refreshToken ? encryptToken(params.refreshToken) : null;

    const { error } = await supabase.from('meta_connections').upsert({
      user_id: params.userId,
      meta_user_id: params.metaUserId,
      provider: params.provider,
      encrypted_access_token: encryptedAccessToken, // Only ciphertext envelope stored
      encrypted_refresh_token: encryptedRefreshToken,
      expires_at: params.expiresAt ? params.expiresAt.toISOString() : null,
      updated_at: new Date().toISOString()
    });

    if (error) throw error;
    return true;
  }

  /**
   * Retrieve and decrypt token transiently in server memory ONLY for authorized Meta Graph API calls
   */
  static async getDecryptedToken(userId: string, provider = 'facebook'): Promise<string | null> {
    const supabase = getServiceSupabase();
    const { data, error } = await supabase
      .from('meta_connections')
      .select('encrypted_access_token')
      .eq('user_id', userId)
      .eq('provider', provider)
      .maybeSingle();

    if (error || !data?.encrypted_access_token) return null;
    // Decrypted ONLY in transient memory; never returned to frontend clients
    return decryptToken(data.encrypted_access_token);
  }
}
```

All persistent credential storage is housed in the managed Supabase PostgreSQL database. Tokens are stored strictly in their encrypted envelope format (`enc_gcm_v2_...`).

## 3. Backend Access Control & Row Level Security (RLS)

Ralion enforces defense-in-depth access controls using PostgreSQL Row Level Security (RLS) to ensure that only authenticated server-side service workers can access credential vaults.

```sql
-- Location: packages/database/migrations/20260815_social_connections_unified.sql

-- Enable Row Level Security
ALTER TABLE public.social_connections ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.social_credentials ENABLE ROW LEVEL SECURITY;

-- Policy 1: Multi-tenant user isolation for metadata
CREATE POLICY "Users can only view their own connections"
    ON public.social_connections
    FOR SELECT
    USING (auth.uid() = user_id);

-- Policy 2: STRICT ISOLATION FOR CREDENTIAL VAULT
-- Standard users, anon roles, and public clients CANNOT SELECT, INSERT, UPDATE, or DELETE credentials
CREATE POLICY "Strict Service Role Only Access to Credentials"
    ON public.social_credentials
    FOR ALL
    USING (auth.role() = 'service_role')
    WITH CHECK (auth.role() = 'service_role');
```

### 3.1 Architectural Impact
* **Direct Client Queries Blocked:** Any client-side request executing `supabase.from('social_credentials').select('*')` returns an empty array or `403 Permission Denied`.
* **Tenant Isolation:** Users cannot query another tenant's connections or credentials.
* **Server-Side Brokerage:** Token decryption is performed exclusively by server-side Edge Functions or Next.js server actions authenticated with the `SUPABASE_SERVICE_ROLE_KEY`.

## 5. Logging Protection & Automatic Secret Redaction

**Meta API user access tokens must NEVER appear in cleartext in application logs or audit logs.**

### 5.1 Redaction Engine Implementation (`apps/ralion/src/lib/services/auditLogger.service.ts`)
```typescript
// Location: apps/ralion/src/lib/services/auditLogger.service.ts

const SENSITIVE_PATTERNS = [
  /password/i,
  /token/i,
  /secret/i,
  /authorization/i,
  /cookie/i,
  /key/i,
  /credential/i,
  /hash/i,
  /signature/i
];

export function sanitizeMetadata(data: any, depth = 0): any {
  if (depth > 5) return '[TRUNCATED_DEPTH]';
  if (!data || typeof data !== 'object') return data;

  if (Array.isArray(data)) {
    return data.map(item => sanitizeMetadata(item, depth + 1));
  }

  const sanitized: Record<string, any> = {};
  for (const [key, value] of Object.entries(data)) {
    const isSensitive = SENSITIVE_PATTERNS.some(pattern => pattern.test(key));
    if (isSensitive) {
      sanitized[key] = '[REDACTED_SENSITIVE_DATA]';
    } else if (typeof value === 'object' && value !== null) {
      sanitized[key] = sanitizeMetadata(value, depth + 1);
    } else {
      sanitized[key] = value;
    }
  }
  return sanitized;
}
```
